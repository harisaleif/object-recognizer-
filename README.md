# object-recognizer-
Raspberry Pi Object Recognition System

A hands-on computer vision project built with a Raspberry Pi 3 Model B, Python, and OpenCV. Developed in 2022, the system demonstrated real-time object recognition in an interactive public setting.

The project was presented at the Πανελλήνιο Συνέδριο Πληροφορικής, where visitors could place objects in front of a webcam and observe the system process the live camera feed.

Hardware

* Raspberry Pi 3 Model B
* USB webcam
* 3D-printed enclosure
* Camera mount positioned above the demonstration area

Software

* Python
* OpenCV
* Raspberry Pi OS

How It Works

The webcam captures a live video feed of the demonstration area. The Raspberry Pi processes the frames using OpenCV and identifies objects within the camera’s field of view.

The fixed overhead camera position provided a consistent viewpoint and helped visitors place objects within the detection area. The system was designed as an educational demonstration of computer vision on compact embedded hardware.

Technical Challenges

The project required processing live webcam input on the resource-constrained Raspberry Pi 3 Model B. Key challenges included:

* Maintaining responsive real-time processing
* Managing camera positioning and visibility
* Integrating hardware, software, and enclosure design
* Creating a reliable setup for repeated public demonstrations
* Explaining the results to visitors with different technical backgrounds

3D-Printed Enclosure
I designed and 3D-printed a custom enclosure to organize and protect the electronics while supporting the webcam above the demonstration area. The design considered component layout, camera visibility, accessibility, and stability.

Public Demonstration

The project was presented at the Πανελλήνιο Συνέδριο Πληροφορικής in 2022. Its interactive format helped visitors understand computer vision by allowing them to see object recognition in action.
